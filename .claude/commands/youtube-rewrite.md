# YouTube 视频洗稿 + TDK 生成

输入一条 YouTube 视频链接，自动提取字幕，改写为结构完整、风格统一的新脚本，并配套生成 TDK（标题/描述/关键词）。

## 使用方式

```
/youtube-rewrite <YouTube 视频链接>
```

## 参数

- `$ARGUMENTS`: 完整的 YouTube 视频链接（如 `https://www.youtube.com/watch?v=xxxxxx`）

---

## 执行步骤

### 第一步：获取视频基础信息

从链接中提取 video_id，然后**并行**调用：
- `mcp__vidIQ_for_Claude__vidiq_video_watch` — 获取标题、描述、标签、时长、发布时间
- `mcp__vidIQ_for_Claude__vidiq_video_stats` — 获取播放量、点赞数、评论数
- `mcp__vidIQ_for_Claude__vidiq_video_transcript` — 获取完整字幕文本

### 第二步：分析原视频结构

拿到字幕后，先做结构拆解，识别：
- 原视频的核心主题是什么
- 原视频的论点/信息密度如何
- 原视频的语言风格（口语/书面/专业/娱乐）
- 哪些信息值得保留，哪些冗余可以删除

不要输出这一步的分析过程，内部处理即可。

### 第三步：改写脚本

按以下规范改写，**严格执行每一条**：

**语言规范**
- 全部输出使用**简体中文**，无论原视频是什么语言
- 如原视频为英文/日文/其他语言，先理解内容再用中文重新表达，不要直译腔

**风格规范**

严格对标以下样本文本的语言风格，这是唯一的风格基准：

```
风格特征提炼（来自样本）：

1. 开篇用极度具体的数字+场景画面制造冲击感
   示例：「在大西洋水下600英尺的无底深渊，一艘价值27亿美元的核潜艇正无声滑过」
   规则：引入第一句必须包含具体数字、地点、动作，禁止用抽象概括开头

2. 句式节奏：长短句交替，形成"冲击—喘息—冲击"的节奏感
   长句铺陈场景细节，短句收尾点睛
   示例：「前6小时上更值班。死死盯住声纳显控台……精神处于极度高压状态。」

3. 用词风格：军事纪录片腔，有力度、有压迫感，但不晦涩
   - 多用动词短语：「撕掉滤镜」「切开防压钢板」「死死卡在」「无缝切换」
   - 修饰词要狠、要具体：「近乎变态的物理数据」「近乎神经质的极致苛求」
   - 避免：「非常」「十分」「很」「比较」等模糊程度词

4. 悬念设计：正文每个段落结尾留钩，引出下一个问题
   示例：「但问题是，在连走廊都只能容纳两人侧身擦肩而过的钢管里，你该如何锻炼？」
   「答案，被藏在了整艘潜艇里最凶猛、同时也最危险的战位——鱼雷舱。」

5. 数据密度高：每个核心观点必须用具体数字支撑
   示例：「平均每天实际睡眠时间只有6.62个小时」
   「仅仅利用20分钟，他们就能做多达300个俯卧撑与400个仰卧起坐」

6. 结构用汉字序号分层：「一、二、三」+小标题，不用「首先其次」

7. 结尾固定格式：升华主题（1-2句）+ 频道签名呼吁互动
   示例：「这里是numberworld / 如果你喜欢我的视频内容 / 欢迎点赞评论 / 打开订阅 / 和我一起解锁世界角落的秘密」
   注意：频道名替换为原视频的频道名，或保持通用表达

8. 禁止出现：「总结一下」「综上所述」「可以看出」「不难发现」「令人惊讶的是」
```

- 句子以短句为主，节奏感强，每句话不超过 30 字
- 零错别字，标点符号规范
- 上下文逻辑严密，每段之间有自然过渡

**结构规范**

```
【引入部分 · 约占全文 20%】
- 钩子（Hook）：前 3 句必须抓住注意力
  设计方向选其一：
  ① 抛出反常识的结论（「你以为 X，其实 Y」）
  ② 提出强烈悬念（「做到这一点，我的 XX 翻了 3 倍」）
  ③ 直接点痛点（「如果你也有这个问题，接下来这 3 分钟很重要」）
- 建立信任：用 1-2 句话交代为什么你有资格讲这个话题
- 预告内容：告诉观众今天能得到什么，激发他们看下去

【正文部分 · 约占全文 80%】
- 分 3-5 个自然段展开
- 每段开头一句话点明这段的核心
- 用具体案例/数据/类比支撑观点，不空谈
- 段与段之间用一句过渡句衔接
- 结尾段给出明确结论或行动建议，不虚收尾
```

**字数限制**
- 脚本总字数控制在 **6000 字以内**（按语速 200 字/分钟，确保朗读时长不超过 30 分钟）
- 如果原视频内容超出这个体量，优先保留核心论点，删除重复举例和冗余铺垫

**禁止事项**
- 不直接翻译原字幕，要重构表达
- 不保留原视频的语气词、口癖、填充词（um、啊、就是那种）
- 不抄原标题的措辞

### 第四步：生成 TDK

脚本写完后，基于新脚本内容生成配套 TDK：

**Title（标题）× 3 个备选**
- 每个标题不超过 30 字
- 包含核心关键词
- 风格分别覆盖：悬念型、利益型、数字型
- 示例格式：
  - 悬念型：「为什么 90% 的人做 XX 都失败了？」
  - 利益型：「学会这 3 点，XX 效率提升 5 倍」
  - 数字型：「XX 个方法，彻底解决 XX 问题」

**Description（简介）**
- 150-200 字
- 第一句话重复核心关键词（有利于 SEO）
- 概述视频核心价值点（3-5 条）
- 结尾引导订阅/点赞/评论

**Keywords（关键词）**
- 输出 10-15 个关键词
- 包含：核心词（2-3个）+ 长尾词（5-8个）+ 相关词（3-4个）
- 格式：用英文逗号分隔
