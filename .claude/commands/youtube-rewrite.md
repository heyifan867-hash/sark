# YouTube 视频洗稿 + TDK 生成

输入一条 YouTube 视频链接，自动提取字幕，改写为结构完整、风格统一的新脚本，并配套生成 TDK（标题/描述/关键词）。

## 使用方式

```
/youtube-rewrite <YouTube 视频链接>
```

## 参数

- `$ARGUMENTS`: 完整的 YouTube 视频链接（如 `https://www.youtube.com/watch?v=xxxxxx`）

---

## 执行步骤

### 第一步：获取视频基础信息

从链接中提取 video_id，然后**并行**调用：
- `mcp__vidIQ_for_Claude__vidiq_video_watch` — 获取标题、描述、标签、时长、发布时间
- `mcp__vidIQ_for_Claude__vidiq_video_stats` — 获取播放量、点赞数、评论数
- `mcp__vidIQ_for_Claude__vidiq_video_transcript` — 获取完整字幕文本

### 第二步：分析原视频结构

拿到字幕后，先做结构拆解，识别：
- 原视频的核心主题是什么
- 原视频的论点/信息密度如何
- 原视频的语言风格（口语/书面/专业/娱乐）
- 哪些信息值得保留，哪些冗余可以删除

不要输出这一步的分析过程，内部处理即可。

### 第三步：改写脚本

按以下规范改写，**严格执行每一条**：

**语言规范**
- 全部输出使用**简体中文**，无论原视频是什么语言
- 如原视频为英文/日文/其他语言，先理解内容再用中文重新表达，不要直译腔

**风格规范**

严格对标以下风格规则，所有规则来自用户提供的多篇样本文本，是唯一的风格基准：

```
【风格规则 · 共12条，全部强制执行】

1. 开篇必须是「沉浸式场景」，第一句直接把读者扔进画面里
   - 用具体数字 + 地点 + 动作，禁止抽象概括开头
   - 示例A：「一艘长达115米的潜艇停在码头，沉重的金属舱门被猛然拉开」
   - 示例B：「每天伴随着72分贝的轰鸣入眠，睡觉不是舒适躺下，而是在电话亭大小的睡袋里悬空面壁」
   - 示例C：「在大西洋水下600英尺的无底深渊，一艘价值27亿美元的核潜艇正无声滑过」

2. 引入部分大量使用「第二人称"你"」制造代入感
   - 让读者感觉自己就在现场经历，而不是在旁观
   - 示例：「你顺着垂直的爬梯向下攀爬，头顶的舱门砰地一声死死锁住」
   - 「你要在这个钢铁棺材里待上整整180天，没有新鲜空气、没有个人隐私」
   - 正文可逐渐切回第三人称，但引入段必须用"你"开场

3. 句式节奏：长短句严格交替，形成「冲击—喘息—冲击」节奏
   - 长句铺陈细节，短句收尾点睛
   - 示例：「前6小时上更值班。死死盯住声纳显控台。精神处于极度高压状态。」
   - 禁止连续三句以上的长句堆砌

4. 用词风格：纪录片解说腔，有力度、有压迫感，但不晦涩
   - 多用强动词短语：「撕掉滤镜」「切开防压钢板」「死死卡在」「无缝切换」「硬生生」「死死锁住」
   - 修饰词要具体狠辣：「近乎变态的物理数据」「反人类的18小时制」「令人毛骨悚然」
   - 绝对禁止：「非常」「十分」「很」「比较」「相当」等一切模糊程度词

5. 悬念钩子：每个段落结尾抛出一个问题或悬念，逼着读者看下去
   - 示例：「但问题是，在连走廊都只能容纳两人侧身擦肩而过的钢管里，你该如何锻炼？」
   - 「答案，被藏在了整艘潜艇里最凶猛、同时也最危险的战位——鱼雷舱。」
   - 问句 + 答案分段，中间制造停顿感

6. 数据密度高：每一个核心论点必须跟一个具体数字
   - 示例：「平均每天实际睡眠时间只有6.62个小时」
   - 「骨密度平均每个月会流失1%到1.5%」
   - 「马桶造价高达1900万美元」
   - 没有数字支撑的论点不能单独成段

7. 黑色幽默：在极端残酷的事实后插入一句反差感强的调侃，释放紧张感
   - 示例：「在空间站里，今天的咖啡就是明天的咖啡」
   - 「在路易斯安那州，我们会做秋葵浓汤，我们也制造金属」
   - 这种幽默要克制，一篇文章用2-3次，不能过多

8. 结构分层：用汉字序号「一、二、三」+小标题划分章节，禁止用「首先/其次/最后」

9. 结尾必须有「哲学升华」段，然后接频道签名
   - 升华段：从具体内容抽象到人类精神/意志层面，1-3句
   - 示例：「人类的骨骼虽然脆弱如粉末，但人类的意志，终究比群星更坚硬」
   - 示例：「正是由于他们选择在寂寞的深渊中默默坚守……才构筑起了大国博弈最坚不可摧的无形护城河」
   - 频道签名格式：「这里是[频道名]，如果你喜欢我的视频内容，欢迎点赞评论，打开订阅」

10. 破折号「——」大量使用，制造停顿和强调感
    - 示例：「唯一的照明来自于头顶上常年维持同等亮度的日光灯——以及机器永不停歇的轰鸣」
    - 「这顿大餐，是指挥官发放的"断头饭"——与士气预支」

11. 引号用法：用双引号「""」给核心概念命名，增加记忆点
    - 示例：「"热铺"」「"潜艇步"」「"潜艇肤色"」「"厄运的龙虾"」「"深海解药"」
    - 每个重要概念第一次出现时加引号并解释

12. 禁止词单：以下词汇绝对不能出现
    「总结一下」「综上所述」「可以看出」「不难发现」「令人惊讶的是」
    「值得注意的是」「由此可见」「毋庸置疑」「众所周知」「不言而喻」
```

- 句子以短句为主，节奏感强，每句话不超过 30 字
- 零错别字，标点符号规范
- 上下文逻辑严密，每段之间有自然过渡

**结构规范**

```
【引入部分 · 约占全文 20%】
- 钩子（Hook）：前 3 句必须抓住注意力
  设计方向选其一：
  ① 抛出反常识的结论（「你以为 X，其实 Y」）
  ② 提出强烈悬念（「做到这一点，我的 XX 翻了 3 倍」）
  ③ 直接点痛点（「如果你也有这个问题，接下来这 3 分钟很重要」）
- 建立信任：用 1-2 句话交代为什么你有资格讲这个话题
- 预告内容：告诉观众今天能得到什么，激发他们看下去

【正文部分 · 约占全文 80%】
- 分 3-5 个自然段展开
- 每段开头一句话点明这段的核心
- 用具体案例/数据/类比支撑观点，不空谈
- 段与段之间用一句过渡句衔接
- 结尾段给出明确结论或行动建议，不虚收尾
```

**字数限制**
- 脚本总字数控制在 **6000 字以内**（按语速 200 字/分钟，确保朗读时长不超过 30 分钟）
- 如果原视频内容超出这个体量，优先保留核心论点，删除重复举例和冗余铺垫

**禁止事项**
- 不直接翻译原字幕，要重构表达
- 不保留原视频的语气词、口癖、填充词（um、啊、就是那种）
- 不抄原标题的措辞

### 第四步：生成双语 TDK（中文 + 日语）

脚本写完后，依次生成两套 TDK：

---

#### 【中文 TDK】

**Title（标题）× 3 个备选**
- 每个标题不超过 30 字
- 包含核心关键词
- 风格分别覆盖：悬念型、利益型、数字型
- 示例格式：
  - 悬念型：「为什么 90% 的人做 XX 都失败了？」
  - 利益型：「学会这 3 点，XX 效率提升 5 倍」
  - 数字型：「XX 个方法，彻底解决 XX 问题」

**Description（简介）**
- 150-200 字
- 第一句话重复核心关键词（有利于 SEO）
- 概述视频核心价值点（3-5 条）
- 结尾引导订阅/点赞/评论

**Keywords（关键词）**
- 输出 10-15 个关键词
- 包含：核心词（2-3个）+ 长尾词（5-8个）+ 相关词（3-4个）
- 格式：用英文逗号分隔

---

#### 【日语 TDK · ネイティブ日本語 SEO 対応】

用地道的日语生成，不是中文直译，要符合日本 YouTube 用户的搜索习惯和表达方式。

**タイトル（Title）× 3 个备选**
- 每个标题控制在 **30〜40 字以内**（YouTube 日语标题的最佳显示长度）
- 必须包含日语用户实际会搜索的核心词（参考下方关键词规则）
- 风格分别覆盖三种日本 YouTube 常见标题模式：
  - **疑問型**（悬念）：用「なぜ？」「〜の真実」「知らないと損」等钩子词
  - **数字型**：「〜の○つの理由」「○分でわかる」「○つの秘密」
  - **衝撃型**（冲击）：「衝撃の事実」「ヤバすぎる」「想像を絶する」「驚愕の」等强情绪词
- 禁止机翻腔，禁止用「〜について」「〜に関して」等过于书面的表达作为标题开头

**概要欄（Description）**
- 200〜300 字（日语字数，日本 YouTube 概要欄的 SEO 最优长度）
- **第一段（最重要）**：前 2〜3 句必须包含核心搜索词，因为只有前 2 行在折叠前可见，这是 CTR 的关键
- 内容结构：
  1. 一句话点明视频核心价值（含关键词）
  2. 本期看点列举（3〜5 条，用「✅」或「▶」开头）
  3. 时间戳章节（如有）
  4. 结尾引导：チャンネル登録・高評価・コメント
- 语气自然亲切，符合日本 YouTube 频道的日常表达，不要翻译腔

**タグ／キーワード（Keywords）**
- 输出 15〜20 个日语关键词，按以下层级分类标注：

  **[核心キーワード]** 2〜3个：最高搜索量、最直接描述视频主题的词
  **[ロングテールキーワード]** 6〜8个：具体的、竞争度低但精准的长尾词，日本用户实际搜索时会打的词组
  **[関連キーワード]** 4〜6个：与主题相关、能扩大曝光范围的周边词

- SEO 备注：每个关键词旁边标注「🔥高競争」「✅中競争」「💡低競争」，帮助判断使用优先级
- 格式：每个关键词独立一行，附带竞争度标注
