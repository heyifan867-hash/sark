# YouTube 自媒体工作流分析

分析指定 YouTube 频道的内容策略与创作工作流，输出可执行的运营洞察报告。

## 使用方式

```
/youtube-workflow <频道名称或频道ID或YouTube频道链接>
```

## 参数

- `$ARGUMENTS`: 频道名称、频道ID（如 `@channelname`）、或频道链接

---

## 执行步骤

**输入**: $ARGUMENTS

按以下顺序完成分析，每步都要实际调用 vidIQ MCP 工具获取真实数据：

### 第一步：定位频道

用 `mcp__vidIQ_for_Claude__vidiq_channel_search` 搜索频道，获取 channel_id。
如果输入已经是频道ID，直接使用。

### 第二步：并行获取基础数据

同时调用以下工具（无依赖关系，并行执行）：
- `mcp__vidIQ_for_Claude__vidiq_channel_stats` — 频道基础统计（订阅数、总播放量、视频数）
- `mcp__vidIQ_for_Claude__vidiq_channel_videos` — 近期视频列表（取最新 20 条）
- `mcp__vidIQ_for_Claude__vidiq_channel_analytics` — 频道整体表现分析
- `mcp__vidIQ_for_Claude__vidiq_similar_channels` — 竞品频道列表

### 第三步：分析爆款视频

从第二步的视频列表中挑选播放量最高的 5 个视频，并行调用：
- `mcp__vidIQ_for_Claude__vidiq_video_stats` — 每个视频的详细数据
- `mcp__vidIQ_for_Claude__vidiq_video_watch` — 视频元信息（标题、描述、标签、时长）

### 第四步：深挖一个爆款视频的内容

对播放量最高的视频，调用：
- `mcp__vidIQ_for_Claude__vidiq_video_transcript` — 获取字幕/脚本，分析内容结构
- `mcp__vidIQ_for_Claude__vidiq_video_comments` — 获取评论，了解观众反应

### 第五步：趋势与关键词

- `mcp__vidIQ_for_Claude__vidiq_channel_performance_trends` — 频道增长趋势
- `mcp__vidIQ_for_Claude__vidiq_outliers` — 超出正常表现的异常爆款视频
- 从爆款标题中提取 2-3 个核心关键词，用 `mcp__vidIQ_for_Claude__vidiq_keyword_research` 分析关键词热度
